从零部署命令（朋友 / 重置）

设备端 SSH 执行以下一行命令即可完成安装（下载发布包→解压→开机自启→启动）：

S="https://gitee.com/wyc-qsmx/c3toolbox/raw/master/install_c3_toolbox.sh"; for P in "" "https://gh-proxy.com/"; do curl -fsSL --retry 8 --retry-delay 3 "${P}${S}" -o /tmp/i.sh && [ -s /tmp/i.sh ] && break; done; chmod +x /tmp/i.sh && bash /tmp/i.sh --reboot
部署脚本读取 GitHub 最新发布包（jsdelivr CDN，国内可达）并写入开机自启。手机须连 C3 同网段（通常 C3 热点 192.168.5.x）才能访问 :5588。
